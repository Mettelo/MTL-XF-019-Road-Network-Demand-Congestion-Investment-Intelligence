# Agreed Acceptance Criteria

1. **AC1:** Observed and estimated traffic records are distinguishable in the curated model and dashboard.
2. **AC2:** Count-point identifiers are validated for longitudinal use and discontinuities are logged.
3. **AC3:** At least five count-point/year values reconcile to the DfT source data.
4. **AC4:** No output labels high traffic volume as congestion unless a separate justified congestion measure is introduced.
5. **AC5:** Priority logic uses a documented multi-year rule rather than one-year volume alone.
6. **AC6:** If forecasting is used, a simple baseline and time-aware validation are included.
7. **AC7:** GIS outputs link only to validated count-point coordinates/road references.
8. **AC8:** A reviewer can rebuild the longitudinal traffic model, core trend analysis and priority outputs from the frozen DfT files.

## Sign-off Rule
Repository files existing is not enough. The panel must verify these criteria from evidence.
