# MTL-XF-019 — Road Network Demand, Traffic Pressure & Infrastructure Investment Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Client | Confidential Regional Transport Infrastructure Authority |
| Sector | Transport / Highways / Infrastructure Investment |
| Duration | 8 weeks |
| Recommended team | 6–8 |
| Sponsor | Director of Transport Strategy |
| Engagement | Simulated confidential-client engagement |

The authority receives more requests for road improvements than it can fund. Current evidence does not consistently separate long-term traffic pressure, vehicle mix, count-point coverage, temporary variation and data-estimation limitations.

**Commissioned decision:** Which corridors and locations warrant the earliest investigation or capital intervention, and where is the evidence insufficient to justify investment?

This is an end-to-end multidisciplinary engagement, not a dashboard-only exercise.

Start with the project, governance, data and submission documents in this repository. Each team creates its delivery repository under the **Mettelo GitHub organisation** and adds every team member using their individual GitHub account.
