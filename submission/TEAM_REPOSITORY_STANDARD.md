# Mandatory Team Repository Standard

Create `MTL-XF-019-<team-name>` under the **Mettelo GitHub organisation** and add every member using their individual GitHub account.

Required folders include `data/`, discovery, governance, data-model, data-quality, KPI, analysis, decision-framework, assurance/UAT and handover documentation, plus `sql/`, `src/`, `notebooks/`, `analysis/`, `dashboard/`, `deliverables/` and `submission/`.

Use issues, meaningful commits, branches, PRs and reviews where practical. One final bulk upload by one person is not appropriate collaborative evidence. `CONTRIBUTIONS.md` records actual contribution; commit count alone is insufficient.
